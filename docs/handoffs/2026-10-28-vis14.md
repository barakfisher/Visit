## Decisions since the last handoff

- **Browser tests run on `visit_test` + Redis db 1, configured in code** (`apps/mobile/scripts/test-environment.ts`). Full reasoning and rejected options are in `docs/architecture/decisions.md` → "Browser test isolation". The short version: sharing the dev database left 4 orphan `qa-north-*`/`qa-south-*` businesses after crashed runs on 2026-10-26, and per-run containers would require Docker everywhere.
- **The harness assigns every API setting explicitly** and fails if `apps/api/src/env.ts` gains a key the harness does not set (`environmentKeys`). Without that, dotenv silently fills new keys from a developer's `.env`, and the suite passes on one machine only.
- **The agenda "price" criterion is checked via the Expected revenue tile.** Agenda cards do not render a per-booking price. If per-card price is wanted, that is a UI change, not a test change.
- **Calendar week width is measured, not fixed** (VIS-11). A fixed 336 px grid hid Saturday at 375 px; `minWidth` + `flexGrow` grew to ~540 px because percentages do not resolve inside a horizontal ScrollView. Now the sheet width comes from `onLayout`, with `CALENDAR_MIN_WIDTH` as the floor.
- **The drawer backdrop is a responder `View`, not a `Pressable`.** React Native Web always gives a Pressable a tabindex (even `focusable={false}`), which put an invisible stop in the keyboard order.

## Lessons (bugs that will recur if forgotten)

- **Hosted CI has never run on this repository.** Every Visit Actions job since the repo was created (2026-10-25, public) ends after ~3 s with zero steps and the message "recent account payments have failed or your spending limit needs to be increased". Payment history is empty, and Trader/Social-Platform (also public, same account, same `ubuntu-latest`) run green. So the block is specific to Visit. Next check is a repository-scoped budget under Billing → Budgets and alerts, then GitHub Support with run `40647104433`. Until it runs, nothing in `.github/workflows/ci.yml` is proven, including whether Prisma creates `visit_test` on the service container.
- **Expo Router keeps earlier screens mounted but hidden.** Locators need `.filter({ visible: true })`, or strict mode fails on duplicates.
- **The app scrolls inside its own container,** so `page.screenshot` misses content unless the element is scrolled into view first.
- **OTP rate limits are per loopback IP.** A suite that adds sign-ins must call `resetLocalSignInLimits()` after itself, or a later suite gets 429.
- **Focus after Escape lands a frame later** on React Native Web. Assert it with `waitForFunction`, never in the same tick.
- **Node and Chromium ICU differ.** Format expected dates inside the page (`page.evaluate`), not in Node.
