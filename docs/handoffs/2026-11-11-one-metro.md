# Visit handoff — 2026-11-11, One Metro for the phone and the browser

PR #65, built on `main` after PR #67. Read `2026-11-11-add-appointment-fixes.md` first. Decision: `decisions.md`, "One Metro for the phone and the browser".

## Where things stand

- **The web build calls `EXPO_PUBLIC_WEB_API_URL` when it is set, and `EXPO_PUBLIC_API_URL` otherwise; native builds ignore the web variable** (`apiAddress` in `apps/mobile/src/lib/apiAddress.ts`, used by `api.ts`). For local development `apps/mobile/.env` holds the Tailscale address in `EXPO_PUBLIC_API_URL` for the phone and `EXPO_PUBLIC_WEB_API_URL=http://localhost:3000` for the browser on `localhost:8081`. This replaces the 2026-11-08 advice to run a second Metro for the browser.
- **The browser suite, its smoke script, CI and Storybook set both variables**, so a local `.env` cannot redirect them.

## Lessons

- **"Can't log in on localhost" while the phone works means the session cookie is on the wrong host.** Sign-in succeeded on the API, but the web bundle called the Tailscale host, whose `HttpOnly; SameSite=Lax` cookie the `localhost:8081` page never sends back, so the profile read failed and the screen showed a connection error. In the browser's network log, look at which host `/api/auth/*` goes to before reading API logs.
- **Expo inlines `EXPO_PUBLIC_*` only when read as a literal `process.env.NAME`.** `api.ts` passes both values to `apiAddress` by name; reading them through a variable or a destructured object leaves them undefined in the bundle. A variable in the shell wins over `.env`.
- **`npx expo start` fails in a fresh worktree** with "Cannot find module 'expo-router/internal/testing'" (typed routes generation). `npx expo export --platform web` and then `npx expo serve dist` checks a bundle without it.

## Not verified

- **`npm run test:web` was not run on this branch.** CI runs it.
- **Sign-in on `localhost:8081` with the real `.env`** was checked only through an exported bundle's requests (all to `localhost:3000`), not by signing in. After pulling: restart Expo with `--clear`, sign in on `localhost:8081`, then open the app on the phone.
