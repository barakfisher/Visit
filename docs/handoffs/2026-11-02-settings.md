## What the user asked for in tasks 2–4

## Lessons (these will recur if forgotten)

- **A new provider route must be added to `safeAuthReturnTo`** (`packages/contracts/index.js`). Otherwise signing in again from that screen silently returns to Home. Only the browser suite caught this. The allowlist names each section exactly; keep it that way.
- **Message dictionaries are merged, and a later duplicate key silently wins.** An unused `setup.publish` in `messages.ts` overrode the new one in `setupMessages.ts`, so the hub showed "Publish business" instead of "Publish your business". Typecheck can't see it. Grep every `src/i18n/*.ts` for a key before adding it.
- **The agenda clears its draft (date, mode, break text) when it unmounts,** by design (`ProviderAgenda.hook.ts`). Any flow that leaves the agenda and comes back must choose the date again. The change didn't break anything; one smoke assumed otherwise.
- **`ProviderAccess` renders nothing for an unfocused screen,** so a stacked screen underneath has no DOM. Back links use `Link dismissTo` and saves use `router.dismissTo`, so returning reuses the existing hub instead of pushing another.
- **When a smoke times out on a locator, print the page's `aria-label`s before guessing.** That found the duplicate-key bug in one run.
- **A session in one worktree can't write files in another.** A hook blocks it. Branch the handoff off `origin/main` inside the current worktree once its own branch is committed and pushed.
